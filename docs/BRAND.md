# 品牌素材

本文维护 DnsGo 标志、配色与素材使用约定。标志或素材路径变化时更新本文，并检查 README、Wiki 首页、导航与浏览器图标的展示。

![DnsGo 标志](/brand/dnsgo-logo.png)

## 标志

正式方向采用圆点与两段圆弧：圆点对应域名中的点与解析目标，圆弧表达解析定位，图文组合使用 `DnsGo` 字标。该方向已由维护者确认。

| 素材 | 文件 | 使用场景 |
| --- | --- | --- |
| 图文组合 PNG | [下载 PNG](/brand/dnsgo-logo.png) | README、白色背景的项目介绍 |
| 独立图形 SVG | [下载 SVG](/favicon.svg) | Wiki 导航、首页、浏览器图标、小尺寸图形 |

PNG 保留已确认设计稿的白色背景与字标。SVG 将圆点和圆弧整理为可缩放的纯色图形，透明背景，独立于字体。SVG 是网站图形的唯一维护源，导航、首页和 favicon 共同引用它。

## 配色与排版

| 用途 | 颜色 |
| --- | --- |
| 标志图形 | `#00ADD8` 青蓝 |
| 图文组合字标 | 深蓝，使用 PNG 中已确认的字形 |

项目名称保持大小写 `DnsGo`。图文组合按原比例缩放，四周保留留白，避免压扁、旋转或为图形添加装饰。深色背景与小尺寸场景使用独立 SVG 图形；需要文字时使用可随主题切换的页面文字。

## 维护

- 素材位于 `docs/public/`，构建时按原路径复制到站点。
- 变更标志时一起更新本页与引用位置，不用本机路径引用生成图片。
- 网站延续既有排版和交互配色，标志使用独立的青蓝色。
- 提交前执行 `npm run docs:check`、`npm run docs:build`，并检查手机、桌面、浅色和深色主题。
